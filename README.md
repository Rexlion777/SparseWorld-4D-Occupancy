# SparseWorld 4D Occupancy

This repository contains the SparseWorld-focused experiment code, diagnostics,
and tests from the local `cv_lidar_transition` workspace.

Tracked scope:

- `scripts/lidar_system_algorithm/sparseworld_mainline/`
- `tests/sparseworld_mainline/`
- `scripts/maintenance/` backup helpers
- lightweight project metadata

Not tracked:

- `day*` learning folders
- datasets, checkpoints, feature caches, artifacts, generated reports, figures,
  videos, logs, and local environments
- large tensor/model files such as `*.pt`, `*.pth`, `*.npz`, `*.npy`, `*.pkl`

The E-drive backup policy is documented in:

```bash
scripts/maintenance/BACKUP_POLICY.md
```
